eCash forknet mining pools

Public pools you can point hashrate at. Each one mines a BIP300/301 forknet, building its blocks from a bip300301_enforcer template so sidechains can actually be merge-mined.

Pools

Point your miner at the stratum URL. Read the payout line first — what you put in the username field differs by mode.

List your pool here

Open a pull request against LayerTwo-Labs/mining-pools adding one object to the pools array in pools.json, then run python3 tools/build.py and commit what it writes. That data is also what feeds pool attribution in the block explorer, so the fields below are not decoration.

Why coinbase_tag matters most. It is the string your pool stamps into the coinbase of every block it finds, and it is the only thing an explorer can use to attribute a block to you. Get it wrong — or leave it at the simplepool default — and your blocks are credited to someone else, silently. Copy it from your running proxy.conf, not from memory.
